# GODIS: A IN-MEMORY DATABASE

## Features:

1. A in-memory database that allows to use strings and hashes
2. A Serialization Protocol that allows the server to receive commands and respond with responses.
3. Multiple connections simultaneously
4. Append Only File (AOF) to write data to to disk. This way, if the server crashes or restarts, we can restore the data.
5. No external libreries.
